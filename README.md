# Saba Ali — Marketing Portfolio

A responsive single-page portfolio built for GitHub Pages. No build tools or dependencies.

## Publish on GitHub Pages
1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Visit `https://YOUR-USERNAME.github.io` once GitHub finishes deployment.

## Before publishing
- Verify outcomes, roles and software proficiency.
- Add your LinkedIn profile URL and preferred contact address.
- Obtain clearance for employer-related case studies and avoid confidential data.
- The Durex digital funnel is expressly labelled a portfolio strategy demonstration, not historical execution.
